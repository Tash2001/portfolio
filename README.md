# Tashini Hendahewa – Portfolio

Personal portfolio website showing my experience, projects, and skills.

**Live site:** https://tash2001.github.io/portfolio

## About

I'm a software engineer (BEng Hons, University of Westminster) working as an Associate Software Engineer. This site collects my work experience, projects, skills, and contact details in one place.

## Built with

- React (Create React App) and React Router (HashRouter)
- Bootstrap 5 and custom CSS
- React Icons
- Formspree for the contact form
- GitHub Pages with `gh-pages` for hosting

## Pages

Home, About, Experience, Projects (with a demo video popup), Skills, and Contact.

## Run locally

```bash
git clone https://github.com/Tash2001/portfolio.git
cd portfolio
npm install
npm start
```

The site opens at http://localhost:3000.

## Deploy

```bash
npm run deploy
```

This builds the app and publishes it to the `gh-pages` branch.
